# Apple SF Symbols assets

X Coder 4.3 is wired to use real SF Symbols when the exported SVG files are present in this folder.

Apple distributes SF Symbols through its SF Symbols app for Apple-platform design/development. Because these artwork files are Apple-provided assets with their own license, this ZIP intentionally does not redistribute the symbol SVGs. Export the symbols you use from the official SF Symbols app, then place the SVGs here using the symbol name as the filename.

Expected filenames include:

- line.3.horizontal.svg
- magnifyingglass.svg
- slider.horizontal.3.svg
- doc.badge.plus.svg
- folder.badge.plus.svg
- ellipsis.svg
- xmark.svg
- chevron.left.svg
- square.on.square.svg
- folder.svg
- doc.svg
- chevron.left.forwardslash.chevron.right.svg
- globe.svg
- apple.terminal.svg
- point.3.connected.trianglepath.dotted.svg
- square.grid.2x2.svg
- sparkles.svg
- arrow.clockwise.svg
- arrow.up.left.and.arrow.down.right.svg
- paperplane.fill.svg
- stop.fill.svg
- gearshape.svg
- folder.fill.badge.plus.svg
- info.circle.svg
- chevron.right.svg
- chevron.down.svg
- trash.svg
- pencil.svg
- square.and.arrow.down.svg
- square.and.arrow.up.svg
- play.fill.svg
- list.bullet.svg
- arrow.up.right.square.svg

If an exported symbol is missing, X Coder automatically falls back to its built-in original SVG icon for that control instead of showing a broken image.
